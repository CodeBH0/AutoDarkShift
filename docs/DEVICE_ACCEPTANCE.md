## 可选诊断

消息回复、事件计数、精确间隔、心跳、sleep/wake、完整后台日志覆盖分别记录为可读取或不可观测。只有轮询样本时，不把轮询冒充 event；有界日志尾部不能代表整个测试时段。没有回复不等于扩展已停止，也不能证明该通信能力永久不可用。

版本不兼容、坏回复、非法参数、运行存储失败和扩展明确拒绝仍需处理。若功能正常而详情不可读取，保留这个结论即可，无需为取得全部诊断字段反复重装。

## 趋势评分与动态采样专项

1. 对照 `trend` 与 `trend_score` 的 A、Δ、V、D、S，确认权重为 0.25 / 0.35 / 0.30 / 0.10，目标由评分 ±0.50 判断。
2. 查看 `sampling_rate_changed`、`activePollInterval` 与 `lastPollInterval`：常规 1 Hz；动态速度绝对值在 0.015 / 0.03 / 0.06 / 0.10 档位边界对应 10 / 30 / 60 / 120 Hz。
3. 变亮 / 变暗逐渐停止后，速度持续低于 0.01 / 秒至少 0.30 秒，应回到 1 Hz；实际退出时刻受观测与调度影响。
4. 验证睡眠、唤醒、异常采样和长间断后重新建立基准；不把缺失采样期间的变化计为连续趋势。
5. 高频仍统计每次事件 / 轮询，常规样本和评分日志被节流；依据计数差和实际采样时间评估达成率。正式代码最高 120 Hz，实验扫描仍在归档。
